# 🌳 Родовід Малеєвих | The Maleev Lineage

> Інтерактивний веб-сайт родоводу, генеалогічного дерева та збереження пам'яті поколінь родини Малеєвих.

---

## ✨ Основні можливості

- **🌳 Інтерактивне генеалогічне дерево (Tree View)**:
  - Візуалізація родинних гілок та поколінь.
  - Плавне масштабування (Zoom), переміщення полотна (Pan & Drag).
  - Зв'язки між подружжям та дітьми.
  - Швидке додавання дитини або подружжя прямо з картки родича.
- **👥 Список роду (Cards View)**:
  - Зручний каталог із картками всіх членів родини.
  - Миттєвий пошук за ім'ям, містом, професією або біографією.
  - Фільтри за статтю, статусом (живі / світла пам'ять), поколінням та тематичними мітками (#Інженер, #Засновник тощо).
- **⏳ Хронологія роду (Timeline View)**:
  - Літопис народжень та важливих віх родини Малеєвих у часі.
- **📊 Статистика та демографія (Stats View)**:
  - Кількість родичів, охоплених поколінь, географія походження та професії.
- **👤 Детальний профіль персони**:
  - Повні імена, дівоче прізвище, роки життя, місця народження й спочинку.
  - Автоматичні клікабельні зв'язки: батьки, подружжя, діти, рідні брати й сестри.
  - Біографія, сімейні спогади та цікаві історії.
- **✏️ Вбудований редактор та збереження (Local + JSON)**:
  - Додавайте родичів та редагуйте профілі прямо у браузері.
  - Дані миттєво зберігаються у вашому браузері (`localStorage`).
  - Можливість експортувати всю базу у файл `.json` та імпортувати назад для передачі рідним або фіксації у GitHub!

## 🚀 Швидкий запуск проєкту

### 1. Встановлення залежностей
```bash
# Якщо використовуєте pnpm:
pnpm install

# Або через npm:
npm install
```

### 2. Запуск локального сервера розробки
```bash
pnpm dev
# або
npm run dev
```

Після запуску відкрийте у браузері адресу: [http://localhost:5173](http://localhost:5173)

### 3. Збірка для публікації
```bash
pnpm build
# або
npm run build
```
Готові оптимізовані файли будуть створені в папці `dist/`.

## 🌐 Як опублікувати сайт в інтернеті безкоштовно

### Варіант 1: GitHub Pages
1. У файлі `vite.config.ts` параметр `base: './'` вже налаштований.
2. Зробіть збірку: `npm run build`
3. Можна скористатися стандартним GitHub Actions workflow або завантажити вміст папки `dist` у гілку `gh-pages`.

### Варіант 2: Vercel / Netlify
1. Підключіть свій репозиторій `https://github.com/Icar6618/The-Maleev-Lineage` на [Vercel](https://vercel.com) або [Netlify](https://netlify.com).
2. Натисніть **Deploy** (система автоматично виконає збірку Vite).

## 📝 Як додавати своїх справжніх родичів

1. **Через інтерфейс сайту**:
   - Натисніть кнопку **"+ Додати родича"** у правому верхньому кутку.
   - Заповніть дані та вкажіть батьків / подружжя.
   - Щоб зберегти базу для сайту назавжди: перейдіть у меню **"Дані" → "Експорт у JSON"**.
2. **Безпосередньо у коді**:
   - Відкрийте файл [`src/data/initialData.ts`](file:///src/data/initialData.ts) та відредагуйте або доповніть масив `persons`.
